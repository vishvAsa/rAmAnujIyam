तार् आर् नऱु मालै कट्टुरैत्ताळ् कट्टुरैया
नीर् एदुम् अञ्जेल्मिऩ् नुम् मगळै नोय् सॆय्दाऩ्
आराऩुम् अल्लऩ् अऱिन्देऩ् अवऩै नाऩ्
कूर् आर् वेल् कण्णीर् उमक्कु अऱियक् कूऱुगेऩो?
आराल् इव् वैयम् अडि अळप्पुण्डदु ताऩ्
आराल् इलङ्गै पॊडि पॊडिया वीऴ्न्ददु मऱ्‌ऱु
आराले कल् मारि कात्तदु ताऩ्? (२१।२।२)

तुळसि निऱैन्द मणम् मिक्क मालैयैयुम् अबिनयित्तुक् काट्टिऩाळ् इदऱ्‌कुप्पिऩ् अवळ् कूऱियदु नीङ्गळ् सिऱिदुम् पयप्पड वेण्डाम् उङ्गळ् पॆण्णै इप्पडि नोवु पडुत्तिऩवऩ् ताऴ्न्द तेवदै अल्ल अवऩ् यार् ऎऩ्बदै नाऩ् अऱिन्देऩ् कूरिय वेल् पोऩ्ऱ कण्गळैयुडैयवर्गळे! नीङ्गळ् अऱियुम्बडि अवऩ् यार् ऎऩ्ऱु उङ्गळुक्कुक् कूऱुगिऱेऩ् याराल् इन्द उलगम् अळक्कप्पट्टदो इलङ्गै याराल् पॊडिबॊडियाग आक्कि अऴिक्कप्पट्टदो मेलुम् याराल् कल्मऴै तडुक्कप्पट्टु पसुक्कळ् काप्पाऱ्‌ऱप्ट्टदो

प्रतिपदार्थः (UV) - DP_२६८४

तिरुत् तुऴाय् = तुळसि निऱैन्द; तार् आर् नऱु मालै = मणम् मिक्क मालैयैयुम्; कट्टुरैत्ताळ् = अबिनयित्तुक् काट्टिऩाळ्; कट्टुरैया = इदऱ्कुप्पिऩ् अवळ् कूऱियदु; नीर् एदुम् = नीङ्गळ् सिऱिदुम्; अञ्जेल्मिऩ् = पयप्पड वेण्डाम्; नुम् मगळै = उङ्गळ् पॆण्णै; नोय् सॆय्दाऩ् = इप्पडि नोवु पडुत्तिऩवऩ्; आराऩुम् अल्लऩ् = ताऴ्न्द तेवदै अल्ल; अवऩै = अवऩ् यार्; नाऩ् अऱिन्देऩ् = ऎऩ्बदै नाऩ् अऱिन्देऩ्; कूर् आर् वेल् = कूरिय वेल् पोऩ्ऱ; कण्णीर् = कण्गळैयुडैयवर्गळे!; उमक्कु = नीङ्गळ् अऱियुम्बडि; अऱिय = अवऩ् यार् ऎऩ्ऱु; कूऱुगेऩो = उङ्गळुक्कुक् कूऱुगिऱेऩ्; आराल् इव् वैयम् = याराल् इन्द उलगम्; अडि अळप्पुण्डदु ताऩ् = अळक्कप्पट्टदो; आराल् इलङ्गै = इलङ्गै याराल्; पॊडि पॊडिया = पॊडिबॊडियाग आक्कि; वीऴ्न्ददु मऱ्ऱु = अऴिक्कप्पट्टदो मेलुम्; आराले कल् मारि = याराल् कल्मऴै तडुक्कप्पट्टु; कात्तदु ताऩ् = पसुक्कळ् काप्पाऱ्ऱप्ट्टदो

०३ आऴि नीर्

विश्वास-प्रस्तुतिः - DP_२६८५ - ०३

आऴि नीर्
आराल् कडैन्दिडप्पट्टदु? अवऩ् काण्मिऩ्
ऊर् आ निरै मेय्त्तु उलगु ऎल्लाम् उण्डु उमिऴ्न्दुम्
आराद तऩ्मैयऩाय् आङ्गु ऒरुनाळ् आय्प्पाडि
सीर् आर् कलै अल्गुल् सीर् अडि सॆन्दुवर् वाय्
वार् आर् वऩमुलैयाळ् मत्तु आरप् पऱ्‌ऱिक्कॊण्डु
एर् आर् इडै नोव ऎत्तऩैयोर् पोदुम् आय्
सीर् आर् तयिर् कडैन्दु वॆण्णॆय् तिरण्डदऩै
वेर् आर् नुदल् मडवाळ् वेऱु ओर् कलत्तु इट्टु
नार् आर् उऱि एऱ्‌ऱि नऩ्गु अमैय वैत्तदऩै
पोर् आर् वेल् कण् मडवाळ् पोन्दऩैयुम् पॊय् उऱक्कम्
ओरादवऩ् पोल् उऱङ्गि अऱिवु उऱ्‌ऱु
तार् आर् तडम् तोळ्गळ् उळ् अळवुम् कै नीट्टि
आराद वॆण्णॆय् विऴुङ्गि (२१।२।३)
