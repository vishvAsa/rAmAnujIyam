पीठिकॆ-सङ्गति–आऴ्वाररु तिरुमलॆय श्रीवेङ्कटेश्वरनल्लि आचार्यर मूलकवे शरणा गति माडिद्दारॆ. श्रीमहालक्ष्मी देविये अवरिगॆ आचार्यळु. अन्था आचार्यळ मूलक माडिद शरणागतिये तनगॆ फलिसलिल्लवल्ल ऎन्दु हिन्दिन पद्यगळल्लि गोळाडिद्दारॆ. फलिसलिल्ल ऎन्दरॆ शर णागति व्यर्थवायितु ऎन्दल्ल. भगवन्त अवरन्नु ऒडनॆये ई प्रकृतियिन्द बिडिसि, मोक्षवन्नीय लिल्लवॆन्दु अवर कॊरगु अदक्कुत्तर इष्टे. भगवन्तनिगॆ, श्रीनिवासनिगॆ, आऴ्वाररु, ईगले संसार दिन्द बिडुगडॆ हॊन्दुमदु इष्टविल्ल. तिरुवाय्मॊऴियॆम्ब घनकार्यवन्नु अवरु आरम्भिसिद्दारॆ. अवरे मुगिस बेकल्लवे? इदु अवन इच्छॆ. आऴ्वाररो अय्यो! ई मुट्ठाळ संसारवन्नु नन्नॊब्बनिन्द तिद्दलादीते! इन्नू ऎष्टो जनरु ई कैङ्कर्यदल्लि तॊडगिसिकॊण्डिद्दारल्लवे? अवरु माडलि, ननगॆ इल्लिन्द बिडुगडॆ माडु” ऎन्नुत्तारॆ श्रीनिवास इदक्कॆ एनुताने उत्तर नीडियानु? आऴ्वाररु श्रीरङ्गदल्लि मलगिरुव रङ्गनाथनन्नु ननॆयुत्तारॆ. श्रीनिवासनन्नु इन्नु नम्बि प्रयोजनविल्ल? ऎन्दु मनदल्ले ऎणिसुत्तारॆ. हेगादरू, ई संसारदिन्द आदष्टु बेग हॊरटु, भगवन्तन पादगळन्नु सेरिबिडबेकु ऎन्दु चडपडिसुत्ता रङ्गनाथनल्लि मॊरॆयिडुत्तारॆ. ई हत्तु पाशुरगळलि आऴ्वाररु तम्मन्ने ताम मरॆतु, तानु, “पराङ्कुश नायकि, रङ्गनाथन प्रेयसि” ऎम्ब भाववन्नु ताळुत्तारॆ. तन्न विरहवन्नु अनुभविसुत्ता कष्टपडुव ई मगळन्नु नोडि, सहिसलारदॆ, स्वामियन्नु अङ्गलाचुव, आक्षेपिसुव, दूरुव तायियागियू, तम्मन्ने भाविसिकॊळ्ळत्तारॆ आऴ्वाररु ई पाशुरगळल्लि तन्न मगळु अळुमदु, गोळाडुमदु, स्वामियन्नु मोहिसुमदु, प्रलापिसुमदु, हुच्चळन्तॆ बडबडिसुमदु, इल्लदिद्दरॆ मूकियन्तॆ माताडदे इरुमदु मुन्ताद ऎल्ला अवस्थॆगळन्नू पडुत्तिरुव तन्नमगळ बगॆ रङ्गनाथन बळि हेळिकॊण्डु अळुत्तारॆ. ईग नाम ई पद्यगळ अर्थगळबग्गॆ हेगॆल्ला योचिसिदरू, अन्दु आऴ्वाररु अनुभविसिदसङ्कट नम्मन्थ सामान्यरिगॆ हेगॆ अर्थवादीतु? ऎन्नुत्तारॆ. श्री कूरत्ताऴ्वाररपुत्रराद श्री पराशरभट्टरु आद्दरिन्द आऴ्वारर ई पाशुरगळ अर्थवन्नु अनुसं धान माडोण. इमगळिगॆ ताय् पाशुरगळु ऎन्दु करॆयुमदु वाडिकॆ. शॆङ्कयल् पाय् नीर् तिरुअरङ्गत्ताय्

मुगिल् वण्णऩ् = मेगवण्णऩाऩ ऎम्बॆरुमाऩिऩ्; अडियै अडैन्दु = तिरुवडिगळै अडैन्दु; अरुळ् सूडि = अवऩुडैय तिरुवरुळै; उय्न्दवऩ् = पॆऱ्ऱु उय्न्दवरुम्; मॊय्प् पुऩल् = मिक्क नीरोडु कूडिऩ; पॊरुनल् = तामिरबरणि तुऱैवरुम्; तुगिल् वण्ण = आडैयिऩ् वण्णम् पोल्; तू नीर्च् चेर्प्पऩ् = तूय्मैयाऩ नीरोडु कूडिऩ; वण् पॊऴिल् सूऴ् = वळम्मिक्क सोलैगळ् सूऴन्द; वण् गुरुगूर् = वण्मैयैयुडैय तिरुक्गुरुगूरिल्; सडगोबऩ् = अवतरित्त नम्माऴ्वार्; मुगिल् वण्णऩ् = मेग वण्णऩाऩ पॆरुमाऩिऩ्; अडिमेल् = तिरुवडिगळैक् कुऱित्तु; सॊऩ्ऩ = अरुळिच् चॆय्द; सॊल् मालै = सॊल् मालैयाऩ; आयिरत्तु = आयिरम् पासुरङ्गळुळ्; इप् पत्तुम् = इन्दप् पत्तुप् पासुरङ्गळैयुम्; वल्लार् = ओद वल्लार्; मुगिल् वण्ण = मेग वण्णमायिरुक्किऩ्ऱ; वाऩत्तु = परमबदत्तिल्; इमैयवर् सूऴ = नित्तियसूरिगळ् सूऴ्न्दिरुक्क; इऩ्ब वॆळ्ळत्ते = पेरिऩ्ब वॆळ्ळत्तिल्; इरुप्पर् पेर् = तिळैप्पार्गळ्

गरणि-प्रतिपदार्थः - DP_३४७४ - ११

मुगिल्वण्णन् =मोडद/(आकाशद) बण्णदवनाद श्रीरङ्गद रङ्गनाथन (पॆरिय पॆरुमाळ् अवर) अडियैअडैन्दु = दिव्यपादगळन्नु आश्रयिसि, अरुळ् शूडि =अवन कृपॆयन्नु तलॆबागिस्वीकरिसि, मुडियल्लिधरिसि, उय्न्दवन् =उज्जीविसिदवरू ऒळ्ळॆय जीवनवन्नु नडॆसुत्तिरुववरू (निन्न विरहदिन्द उण्टाद ताप वन्नु निवारिसिकॊण्डु उत्तमजीवनवन्नु ईग निवारिसिकॊण्डु उत्तम जीवनवन्नु ईग नडॆसुत्तिरु ववरू, मॊय्पुनल् =समृद्धवाद नीरन्नु हॊन्दिरुव, कॊण्डजलत्तै उडैय, पॆरुनल् =ताम्रपर्णी नदिय, तुहिल्वण्णम् =बिळिय वस्त्रदन्तॆ बण्णमळ्ळ, तू =शुद्धवाद, नीर् =तीर्थवन्नु, शेर्प =उपयोगिसुववरू, (अदर दडदल्लि वासिसुत्तिरुववरू) वण् =सुन्दरवाद, पॊऴिल्शूऴ् = तोटग ळिन्द सुत्तुवरियल्पट्ट, वण्कुरुहूर् शटगोपन् = अन्दद ऊरु करुकापुरियल्लिरुव शटगोपन् ऎम्ब(आऴ्वाररु) मुगिल्वण्णनडिमेल् शॊन्न =मेघवर्णदवन अडिदावरॆगळ मेलॆहाडिद, शॊल्मालै आयिरुत्तु = साविरपद्यगळुळ्ळ ई पद्यमालिकॆयल्लि, इप्पत्तुम् वल्लार् = ई हत्तु पद्यगळन्नु अरितु हाडबल्लवरु, मुगिल्वण्णम् वानत्तु =मोडदन्तॆ नीलिबण्णवन्नुळ्ळ वैकुण्ठदल्लि, इमैयवर् शूऴ =इवनन्नु नित्यसूरिगळु सुत्तुवरिदिरलु. पेरिन्बवॆळ्ळत्तुइरुप्पर् =अपरिमितवाद सुखदल्लि ऎन्दू इरुवरु.

गरणि-गद्यानुवादः - DP_३४७४ - ११

ई हत्तु पद्यगळिगॆ इदु फलश्रुति, मेघवर्णनाद श्रीरङ्गनाथन दिव्यपादगळन्नु बुद्धि तिळिदु आश्रयिसि, अनुभविसुत्ता अदरिन्द हिन्दॆ इद्द विरहदिन्द उण्टाद तापवॆल्लवू होगि, ईग हितवागि, ताम्रपर्णी नदीतीरदल्लिरुव तिरुक्कुरुहूर् ऎम्ब ऊरिनल्लि नॆलॆसिरुव शठगोपरु, अनुग्रहिसिद साविरपद्यगळल्लि ईहत्तु पद्यगळन्नु कलितु, अरितु हाडबल्लवरु ई संसारदिन्द बिडु गडॆ हॊन्दि, वैकुण्ठवन्नुसेरि, “हीगॆयू ऒब्बनु भूमियिन्द इल्लिगॆ बरबहुदो ऎन्दु आश्चर्य पडुव नित्यसूरिगळ जॊतॆयल्ले इद्दु अपरिमित आनन्दवन्नू सुखवन्नू अनुभविसुत्तिरुवरु. भग वन्तन सान्निध्य ऎम्ब सन्तोषद प्रवाहदल्लि मुळुगि, तेलुत्तिरुवरु. -०००-
