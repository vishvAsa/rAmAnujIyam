उऱ्ऱीर्गट् कॆऩ्सॊल्लिच् चॊल्लु केऩ्याऩ्

<details><summary>प्रतिपदार्थः (UV) - DP_३२९४</summary>

**ऎऩ्ऩुडै पेदै** = ऎऩ्ऩुडैय पेदैप् पॆण्; **उऱ्ऱार्गळ् ऎऩक्कु** = ऎऩक्कु उऱविऩर्; **यारुम् इल्लै ऎऩ्ऩुम्** = यारुम् इल्लै ऎऩ्गिऱाळ्; **उऱ्ऱार्गळ् ऎऩक्कु इङ्गु** = ऎऩक्कु उऱविऩर् इङ्गु; **ऎल्लारुम् ऎऩ्ऩुम्** = इरुक्कुम् अऩैवरुम् ऎऩ्गिऱाळ्; **उऱ्ऱार्गळै** = उऱविऩर्गळै; **सॆय्वेऩुम्** = उण्डाक्कुवदुम्; **याऩे ऎऩ्ऩुम्** = नाऩे ऎऩ्गिऱाळ्; **उऱ्ऱार्गळै** = उऱविऩर्गळै; **अऴिप्पेऩुम्** = अऴिप्पदुम्; **याऩे ऎऩ्ऩुम्** = नाऩे ऎऩ्गिऱाळ्; **उऱ्ऱार्गळुक्कु** = उऱविऩर्गळुक्कु; **उऱ्ऱेऩुम्** = ऎल्ला उऱवु मुऱैगळुम्; **याऩे ऎऩ्ऩुम्** = नाऩे ऎऩ्गिऱाळ्; **उऱ्ऱार् इलि** = मुयऱ्सियाल् तऩ्ऩै अडैय मुडियाद; **मायऩ् वन्दु** = आच्चर्य सक्ति उडैयवऩ् वन्दु; **एऱक्कॊलो?** = आवेचित्तदऩालो?; **उऱ्ऱीर्गट्कु** = उऱविऩराऩ उङ्गळुक्कु; **उऱ्ऱु** = उळ्ळदै उळ्ळबडि कण्डु; **उरैक्किऩ्ऱ** = सॊल्लुम् वार्त्तैगळै; **याऩ् ऎऩ् सॊल्लि** = ऎदैच् चॊल्लि; **सॊल्लुगेऩ्?** = सॊल्लुवेऩ्?
</details>

<details><summary>गरणि-प्रतिपदार्थः - DP_३२९४ - ०७</summary>

उऱ्ऱार् हळ् = \(ननगिन्त\) उत्तमरु \(दॊड्डवरु, श्रेष्ठरु\), ऎन्नक्कु इल्लै= ननगॆ इल्ल, यारुम् ऎन्नुम् = यारू, ऎन्नुत्ताळॆ, उऱ्ऱार् हळ् = ननगॆ बेकादवरु \(बन्धुगळु\), ऎनक्कु = ननगॆ, इङ्गु = इल्लि \(ई लोकदल्लि\), ऎल्लारुम् = ऎल्लरू, ऎन्नुम् = ऎन्नुत्ताळॆ, उऱ्ऱार् हळै = नन्न बन्धुगळन्नु, शॆय्यवेणुम् = बद्धमाडिकॊळ्ळतक्कवन \(उण्टुमाडिकॊळ्ळतक्कवनु\), याने ऎन्नुम् = नाने ऎन्नुत्ताळॆ, उऱ्ऱार् हळै = हिरिमॆपडुववरन्नु, अऴिप्पेनुम् = नाशपडिसतक्कवनू, याने = नाने, ऎन्नुम् = ऎन्नुत्ताळॆ, उऱ्ऱार् हळुक्कु = ननगॆ बेकादवरिगॆ, उऱ्ऱेनुम् = बन्धुवागतक्कवनू \(ऒदगिबरतक्कवनू\), याने ऎन्नुम् = नाने ऎन्नुत्ताळॆ, उऱ्ऱार् इलि = श्रेष्ठरे \(तनगिन्त हॆच्चिनवरे इल्लद\), मायन् = आश्चर्यकारियु \(मायनु\), वन्दु = बन्दु, एऱिकॊलो = आवाहनॆगॊण्डिद्दानो हेगो, उऱ्ऱीर् हट्कु = लोकिगरराद निमगॆ \(इहलोकद नन्न बन्धुगळि\), ऎन् शॊल्लुहेन् = एनु हेळलि, यान् = नानु, उऱ्ऱ = वास्तववागियू \(नडॆदद्दु नडॆद हागॆ\), ऎन्नुडै = नन्न, पेदै = अरिवु काणद मगळु \(अज्ञानि मगळु\), उरैक्किन्ऱवे = हेळुव मातुगळे इवु. 
</details>

<details><summary>गरणि-गद्यानुवादः - DP_३२९४ - ०७</summary>

’यारू ननगिन्त श्रेष्ठरिल्ल’ ऎन्नुत्ताळॆ. इहलोकदल्लिरुववरॆल्लरू ननगॆ बेकादवरे \(बन्धुगळे\)” ऎन्नुत्ताळॆ. “ननगॆ बेकादवरन्नु उण्टुमाडिकॊळ्ळतक्कवनू नाने” ऎन्नुत्ताळॆ. “हिरिमॆपडुववरन्नु नाशपडिसुववनू नाने” ऎन्नुत्ताळॆ. “ननगॆ बेकादवरिगॆ ऒदगिबरतक्कवनू नाने” ऎन्नुत्ताळॆ. तनगिन्त हॆच्चिनवरे इल्लद आ मायनु बन्दु आवाहनॆगॊण्डिद्दानो हेगो? इहलोकद नन्न बन्धुगळाद निमगॆ नानेनु हेळलि? वास्तववागियू नन्न अरिवु काणद मगळु हेळुव मातुगळे इवु. 
</details>

<details><summary>गरणि-विस्तारः - DP_३२९४ - ०७</summary>

भगवन्तन कृपॆय वैशाल्यवन्नु ऎष्टु सुन्दरवागि इल्लि वर्णिसिद्दारॆ, कण्डिरा\! 

“उऱ्ऱार् हळ् ऎनक्किल्लैयारुम्” – “नाने सर्वश्रेष्ठ. ननगिन्तलू दॊड्डवरु इल्लवे इल्ल” – भगवन्तन विषयदल्लि इरु सत्यपूर्णवाद मातु.

“उऱ्ऱार् हळ् ऎनक्किङ्गु ऎल्लारुम्” – ई लोकदल्लिरुव ऎल्ला चेतन अचेतन वस्तुगळु नन्निन्द सृष्टिगॊण्डद्दरिन्द, ऎल्लरल्लू ननगॆ तायिय ममतॆ इदॆ. 

“उऱ्ऱार् हळै शॆय्यवेणुम् याने” – “नन्निन्द सृष्टिगॊण्डु, नन्नवॆरॆनिसिकॊण्डु, नन्नन्नु मरॆतु तावे हॆच्चॆन्दु हॆम्मॆपडुववरन्नु नाशपडिसुववनू नानॆ” – कंस, जरासन्ध मुन्तादवरु, निदर्शनक्कॆ. 

“उऱ्ऱीर् हट्कु ऎन् शॊल्लुहेन् यान्” – लोकिगरु भगवद्विषयद कडॆगॆ हॆच्चागि गमन कॊडुववरल्ल. इन्द्रियगळु अवर मनस्सन्नु विषय सुखगळ कडॆगॆ सॆळॆदु भगवन्तनन्नु मरॆसुत्तवॆ. अन्थवरिगॆ भगवद्विषयवन्नु ऎष्टॆष्टु सरळवागि हेळिदरू हिडियुवुदिल्ल. एकॆन्दरॆ, इन्द्रियगळु मनस्सन्नु स्वाधीनपडिसिकॊण्डु प्रापञ्चिक सुखद कडॆगे सॆळॆयुत्तवॆ. 

’नायकि’य तायि हेळुत्ताळॆ- तायन्दिरे, अरिवु काणद नन्न मगळु हेळुव मातुगळु निमगॆविचित्रवागि काणुवुदिल्लवे? अवळाडुव मातुगळ वास्तविकतॆयन्नु तिळिदु \(गमनिसि\) नोडि. ऎल्लवू भगवन्तनिगॆ सम्बन्धिसिदवे. अवने अवळल्लि आवाहनॆगॊण्डु ई मातुगळन्नु अवळ बायल्लि आडिसुत्तिद्दानो हेगो? इष्टल्लदॆ निमगॆ नानु बेरॆ एनन्नु हेळलि.
</details>
