ऎन्नमर्पॆरुमान् इमैयवर् पॆरुमान् इरुनिलमिडन्दवॆम्बॆरुमान्
मुन्नैवल्विनैगळ् मुळुदुडन्माळ ऎन्नैयाळ्गिन्र वॆम्बॆरुमान्
तॆन्तिशैक्कणिगॊळ्तिरुच्चॆङ्गुन्रूरिल् तिरुच्चिऱ्ऱाऱ्ऱङ्गरैमीपाल्
निन्रवॆम्बॆरुमान् अडियल्लाल् शरण् निनैप्पिलुम् पिरिदिल्लैयॆनक्के.

मुन्नैवल्विनैगळ् मुळुदुडन्माळ ऎन्नैयाळ्गिन्र वॆम्बॆरुमान्
तॆन्तिशैक्कणिगॊळ्तिरुच्चॆङ्गुन्रूरिल् तिरुच्चिऱ्ऱाऱ्ऱङ्गरैमीपाल्
निन्रवॆम्बॆरुमान् अडियल्लाल् शरण् निनैप्पिलुम् पिरिदिल्लैयॆनक्के.

प्रतिपदार्थः (UV) - DP_३५९८

इमैयवर् = नित्यसूरिगळिऩ्; पॆरुमाऩ् = नादऩाऩवऩुम्; ऎऩ् अमर् = ऎऩक्कु अऩुरूपमाऩ; पॆरुमाऩ् = पॆरुमाऩुम्; इरु निलम् = पिरळयत्तिल् पूमियै; इडन्द = इडन्दु ऎडुत्त; ऎम् पॆरुमाऩ् = ऎम् पॆरुमाऩुम्; मुऩ्ऩै = अनादियाऩ; वल्विऩैगळ् = तीविऩैगळॆल्लाम्; मुऴुदु उडऩ् मुऴुवदुम् = ऒरु नॊडिप् पॊऴुदिल्; माळ = माळुम्बडियाग; ऎऩ्ऩै आळ्गिऩ्ऱ = ऎऩ्ऩै अडिमै कॊळ्ळुम्; ऎम् पॆरुमाऩ् = ऎम् पॆरुमाऩाऩवऩ्; तॆऩ् तिसैक्कु = तॆऩ् तिसैक्कु; अणि कॊळ् = अलङ्गारमाग इरुक्कुम्; तिरुच्चॆङ्गुऩ्ऱूरिल् = तिरुच्चॆङ्गुऩ्ऱूरिल्; तिरुच्चिऱ्ऱाऱ्ऱाङ्गरै = तिरुच्चिऱ्ऱाऱ्ऱाङ्गरैयिऩ्; मीबाल् = मेल् पक्गतिल् इरुप्पवऩाग; निऩ्ऱ ऎम् पॆरुमाऩ् = निऩ्ऱ ऎम् पॆरुमाऩिऩ्; अडि अल्लाल् सरण् = तिरुवडिगळैत् तविर्त्तु; पिऱिदु ऎऩक्के = वेऱु ऒऩ्ऱु ऎऩ्; निऩैप्पिलुम् इल्लै = निऩैविल् इल्लै

गरणि-प्रतिपदार्थः - DP_३५९८ - ०३

इमैयवर्पॆरुमान् =नित्यसूरिगळिगॆऒडॆयनु,ऎन् अमर्पॆ रुमान् =नन्नूळॆगे स्थिरवागि निन्तिरुव अन्तर्यामियाद स्वामियु, इरुनिलम् =वासमाडुव स्थळम, इडन्द =प्रळय समुद्रदल्लि हुदुगि होगि द्द भूमियन्नु तन्नकोरॆगळिन्द मीटि मेलॆतन्द, ऎम्बॆरुमान् =नन्न स्वामि ये!, मुन्नै =हिन्दॆमाडिद, वल्विनैहळ् =कडु पापगळ फलवाद कर्मम, मुऴुदुडन् =पूर्तियागि, उडन् =ऒन्देक्षणदल्लि, माळ =नाशवागुवन्तॆ, ऎन्नैआळ्हिन्ऱ =नन्नन्नु अवरिसिकूण्डु, आळुत्तिरुव, ऎम्बॆ रुमान् =नन्नस्वामियु, महापुरुषनादवनु, तॆन्तिशैक्यु =दक्षिणदिक्किगॆ, अणिकूळ् =अलङ्कारप्रायवागिरुव, तिरुच्चॆङ्गन्रूरिल् =तिरुच्चित्तारुऎम्ब नदितीरदल्लिरुवतिरुच्चॆङ्गन्रूरिनल्लि,मीपाल् = मेल्भा गदल्लि, निन्ऱ =नॆलॆनिन्तिरुव, ऎम्बॆरुमान् =नन्न महिमॆयुळ्ळ स्वामिय, अडिअल्लाल् =पादरविन्दगळल्लदे, ऎनक्कु =ननगॆ, निनैप्पदिलुम्पिऱिदु शरण् इल्लै =नॆनॆयुमदक्कू हॆच्चॆन अथवा बेरॆ

गरणि-गद्यानुवादः - DP_३५९८ - ०३

याद शरणु हून्दुव जागम ननगॆ बेरॊन्दिल्ल.

गरणि-विस्तारः - DP_३५९८ - ०३

नित्यसूरिळिगॆ ऒडॆयनागि, अवरूडनॆ इरुमदु तनगॆ हेगॆ भूग्यवागिदॆयॆन्दु भाविसुवनो, अदे रीतियागि, नन्नॊडनॆ, नन्नॊळगॆइद्दु अन्तर्यामियागिरुमदन्नु भोग्यवागि परिगणिसु त्तानॆ. अन्थानन्न स्वामि! वासमाडुव स्थळवे तिरुच्चॆङ्गन्रूरु. “हिन्दॊम्मॆ प्रळय समुद्रदल्लि हुदुगिहोगिद्द भूमियन्नु तन्न कोरॆगळिन्द मेलॆत्तिद. स्वामिये! नानु अनेक कालगळिन्द माडिद्द कडुघोरपापद फलवादकर्मम ऒन्दे क्षणदल्लि नाशमाडुवन्तॆ नन्नन्नु आवरिसि कॊण्डु, नन्नन्नाळुव महापुरुषनाद स्वामिये! तिरुच्चॆत्तारुऎम्ब नदीतीरदल्लिरुव तिरुच्चॆङ्ग न्रूरिनल्लि वासवागिरुव महामहिमनाद स्वामिय पादरविन्दगळल्लदे बेरावस्थळम नॆनॆयलु शरणुहॊन्दलु ननगॆ साध्यवागुमदल्ल.
