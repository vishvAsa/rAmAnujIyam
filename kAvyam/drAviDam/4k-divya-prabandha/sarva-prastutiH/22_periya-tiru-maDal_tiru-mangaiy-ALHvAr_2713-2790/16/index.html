अर्थः (UV) - DP_२७६८

तविरवुम् मेलुम् तऩदु स्वरूबत्तै यारुम् अऱियादबडि परमबुरुषऩाऩ ताऩ् ऒरु पिरम्मसारि उरुविल् मगाबलियिऩ् वेळ्वियिल्

प्रतिपदार्थः (UV) - DP_२७६८

मऱ्ऱु इऩ्ऱियुम् = तविरवुम् मेलुम्; तऩ् उरुवम् आरुम् = तऩदु स्वरूपत्तै यारुम्; अऱियामल् = अऱियादबडि; ताऩ् अङ्गु ओर् मऩ्ऩुम् = परमबुरुषऩाऩ ताऩ् ऒरु; कुऱळ् उरुविल् = पिरम्मसारि उरुविल्; माणियाय् मावलि तऩ् = मगाबलियिऩ् वेळ्वियिल्

अर्थः (UV) - DP_२७६९

तङ्गम् ताऩम् सॆय्यप्पडुम् याग पूमियिल् पोय्च्चेर्न्दु पोर् सॆय्यवल्ल मिडुक्कै उडैय अन्द मगाबलियै यासिप्पदऱ्‌कागवे वन्दाऩॆऩ्ऱु नम्बुम्बडियाग मयक्कि नडैयऴगु सॊल्लऴगु आगियवऱ्‌ऱाल् मऩदै उरुक्कि ऎऩ्ऩुडैय पादत्ताल् नाऩे अळन्दु कॊळ्ळुम्बडि मूवडि मण् मऩ्ऩऩे ऎऩक्कुत् तरुवायाग ऎऩ्ऱु यासिक्क

प्रतिपदार्थः (UV) - DP_२७६९

पॊऩ् = तङ्गम् ताऩम्; इयलुम् = सॆय्यप्पडुम्; वेळ्विक् कण् = याग पूमियिल्; पुक्कु इरुन्दु = पोय्च्चेर्न्दु; पोर् = पोर् सॆय्यवल्ल; वेन्दर् = मिडुक्कै उडैय; मऩ्ऩै मऩम् = अन्द मगाबलियै; कॊळ्ळ = यासिप्पदऱ्कागवे वन्दाऩॆऩ्ऱु; वञ्जित्तु = नम्बुम्बडियाग मयक्कि नडैयऴगु सॊल्लऴगु; नॆञ्जु उरुक्कि = आगियवऱ्ऱाल् मऩदै उरुक्कि; ऎऩ्ऩुडैय पादत्ताल् = ऎऩ्ऩुडैय पादत्ताल्; याऩ् अळप्प = नाऩे अळन्दु कॊळ्ळुम्बडि; मूवडि मण् = मूवडि मण्; मऩ्ऩा तरुग! = मऩ्ऩऩे ऎऩक्कुत् तरुवायाग; ऎऩ्ऱु वाय् तिऱप्प = ऎऩ्ऱु यासिक्क

अर्थः (UV) - DP_२७७०

मगाबलियुम् तऩ्ऩाल् मूवडि निलम् कॊडुक्कप्पट्टदु ऎऩ्ऱु सॊल्ल अन्दक्षणत्तिलेये मणिमगुडम् आगासत्ते पोय् अळाव मेले तूक्किऩ

प्रतिपदार्थः (UV) - DP_२७७०

मऱ्ऱु अवऩुम् = मगाबलियुम्; ऎऩ्ऩाल् = तऩ्ऩाल्; तरप्पट्टदु = मूवडि निलम् कॊडुक्कप्पट्टदु; ऎऩ्ऱलुमे = ऎऩ्ऱु सॊल्ल; अत्तुणैक्कण् = अन्दक्षणत्तिलेये; मिऩ् आर् मणि मुडि = मणिमगुडम्; पोय् विण् तडव = आगासत्ते पोय् अळाव; मेल् ऎडुत्त = मेले तूक्किऩ

अर्थः (UV) - DP_२७७१

पॊऩ्ऩालाऩ वीरत्तण्डै अणिन्द तिरुवडि एऴु उलगङ्गळैयुम् ताण्डि अन्द याग पूमियिलुळ्ळ नमुसि मुदलिय असुरर्गळ् तुऩ्बप्पडुम्बडि मेलुम् वियाबिक्कच्चॆय्दु नित्यमाय् विसालमाऩ इप्पू मण्डलत्तै मगाबलियै वञ्जित्तु इन्द उलगत्तैत् तऩ्ऩुडैयदागवे आक्किगॊण्ड तिरुवडिगळैयुडैय पॆरुमाऩै
