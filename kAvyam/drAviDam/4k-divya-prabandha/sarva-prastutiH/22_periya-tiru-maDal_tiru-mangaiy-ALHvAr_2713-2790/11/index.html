०१ अऩ्ऩम् आय् माऩ् आय् अणि मयिल् आय् आङ्गु इडैये

विश्वास-प्रस्तुतिः - DP_२७५६ - ०१

अऩ्ऩम् आय् माऩ् आय् अणि मयिल् आय् आङ्गु इडैये
मिऩ् आय् इळ वेय् इरण्डु आय् इणैच् चॆप्पु आय्
मुऩ् आय तॊण्डै आय् कॆण्डैक् कुलम् इरण्डु आय्
अऩ्ऩ तिरु उरुवम् निऩ्ऱदु अऱियादे
ऎऩ्ऩुडैय नॆञ्जुम् अऱिवुम् इऩ वळैयुम्
पॊऩ् इयलुम् मेगलैयुम् आङ्गु ऒऴियप् पोन्देऱ्‌कु
मऩ्ऩु मऱिगडलुम् आर्क्कुम् मदि उगुत्त
इऩ् निलाविऩ् कदिरुम् ऎऩ् तऩक्के वॆय्दु आगुम्
तऩ्ऩुडैय तऩ्मै तविर ताऩ् ऎऩ्गॊलो? (२२।११।१)

अऩ्ऩम् पोऩ्ऱुम् माऩ् पोऩ्ऱुम् अऴगिय मयिल् पोऩ्ऱुम् मिऩ्ऩल् पोऩ्ऱ इडैयोडुम् मूङ्गिलै ऒत्त इरु तोळ्गळोडुम् इरण्डु कलसम् पोऩ्ऱ मार्बगङ्गळोडुम् कॊव्वैक् कऩियै पोऩ्ऱ अदरत्तोडुम् कॆण्डै मीऩ्गळै पोऩ्ऱ कण्गळोडुम् अप्पडिप्पट् उरुवमाऩ पिराट्टि अरुगिलिरुप्पदै अऱियामल् अन्द नॆञ्जुम् मऱ्‌ऱुम् अऱिवुम् सिऱन्द कै वळैयुम् तङ्गमयमाऩ मेगलैयुम् ऎल्लाम् विट्टु विट्टु नीङ्ग पॆऱ्‌ऱ ऎऩक्कु इदऱ्‌कु मेलुम् अलैयुडैय कडलुम् ऎऩक्कु मट्टुमे सप्तिक्कामल् निऱ्‌किऱदु सन्दिरऩ् वॆळियिडुगिऱ इऩिय निलविऩ् ऒळियुम् ऎऩक्कु मट्टुम् वॆप्पत्तैक् कॊडुप्पदाग उळ्ळदु निलविऩ् स्वबावमागिय कुळिर्त्ति तविर्न्दु इप्पडि वॆप्पमागुम्बडि ऎम्बॆरुमाऩ् ताऩ् एदावदु सॆय्दुविट्टाऩो

प्रतिपदार्थः (UV) - DP_२७५६

अऩ्ऩम् आय् = अऩ्ऩम् पोऩ्ऱुम्; माऩ् आय् = माऩ् पोऩ्ऱुम्; अणि मयिलाय् = अऴगिय मयिल् पोऩ्ऱुम्; आङ्गु = मिऩ्ऩल् पोऩ्ऱ; मिऩ् इडैये आय् = इडैयोडुम्; इळ वेय् = मूङ्गिलै ऒत्त; इरण्डाय् = इरु तोळ्गळोडुम्; इणै = इरण्डु कलसम् पोऩ्ऱ; सॆप्पु आय् = मार्बगङ्गळोडुम्; मुऩ् आय् = कॊव्वैक् कऩियै पोऩ्ऱ; तॊण्डै आय् = अदरत्तोडुम्; कॆण्डैगुलम् = कॆण्डै मीऩ्गळै; इरण्डु आय् = पोऩ्ऱ कण्गळोडुम्; अऩ्ऩ तिरु उरुवम् = अप्पडिप्पट् उरुवमाऩ पिराट्टि; निऩ्ऱदु = अरुगिलिरुप्पदै; अऱियादे = अऱियामल्; ऎऩ्ऩुडैय नॆञ्जुम् = अन्द नॆञ्जुम्; अऱिवुम् = मऱ्ऱुम् अऱिवुम्; इऩ वळैयुम् = सिऱन्द कै वळैयुम्; पॊऩ् इयलुम् = तङ्गमयमाऩ; मेगलैयुम् = मेगलैयुम्; आङ्गु ऒऴिय = ऎल्लाम् विट्टु विट्टु नीङ्ग; पोन्देऱ्कु = पॆऱ्ऱ ऎऩक्कु इदऱ्कु मेलुम्; मऩ्ऩु मऱि कडलुम् = अलैयुडैय कडलुम्; आर्क्कुम् = ऎऩक्कु मट्टुमे सप्तिक्कामल् निऱ्किऱदु; मदि उगुत्त = सन्दिरऩ् वॆळियिडुगिऱ; इऩ् निलाविऩ् = इऩिय निलविऩ्; गतिरुम् ऎऩ् तऩक्के = ऒळियुम् ऎऩक्कु मट्टुम्; वॆय्दु आगुम् = वॆप्पत्तैक् कॊडुप्पदाग उळ्ळदु; तऩ्ऩुडैय त ऩ्मै = निलविऩ् स्वबावमागिय कुळिर्त्ति; तविर ताऩ् = तविर्न्दु इप्पडि वॆप्पमागुम्बडि; ऎऩ्गॊलो = ऎम्बॆरुमाऩ् ताऩ् एदावदु सॆय्दुविट्टाऩो

०२ तॆऩ्ऩऩ् पॊदियिल् सॆऴुम् सन्दिऩ् तादु अळैन्दु

तॆऩ्ऩऩ् पॊदियिल् सॆऴुम् सन्दिऩ् तादु अळैन्दु
मऩ् इव् उलगै मऩम् कळिप्प वन्दु इयङ्गुम्
इऩ् इळम् पून् दॆऩ्ऱलुम् वीसुम् ऎरि ऎऩक्के
मुऩ्ऩिय पॆण्णैमेल् मुळ् मुळरिक् कूट्टगत्तु
पिऩ्ऩुम् अव् अऩ्ऱिल् पेडै वाय्च् चिऱु कुरलुम्
ऎऩ्ऩुडैय नॆञ्जुक्कु ओर् ईर् वाळाम् ऎऩ् सॆय्गेऩ्? (२२।११।२)

तॆऩ् तिसैयिल् पाण्डिय अरसऩिऩ् पॊदिय मलैयिलुळ्ळ अऴगिय सन्दऩ मरत्तिऩ् पून्दादुक्कळै अळैन्दु कॊण्डु नित्यमाऩ इन्द उलगत्तिलुळ्ळवर्गळ् मऩम् मगिऴ वन्दु उलावुम् इऩिय इळम् तॆऩ्ऱल् काऱ्‌ऱुम् ऎऩक्कु मट्टुम् वॆप्पत्तै वीसुगिऩ्ऱदु ऎदिरे काणप्पडुगिऱ पऩै मरत्तिल् मुळ्ळैयुडैय तामरैत् तण्डिऩाल् सॆय्यप्पट्ट कूट्टिल् वायलगु कोत्तुक् कॊण्डिरुक्कुम् अऩ्ऱिल् पेडैयिऩ् वायिलिरुन्दु ऎऴुम् सिऱु कुरलुम् ऎऩ् नॆञ्जै पिळक्कुम् ऒरु वाळाग इरुक्किऱदु तप्पिप्पिऴैक्क नाऩ् ऎऩ् सॆय्वेऩ्?
